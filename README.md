# HelpCart

HelpCart is a modern platform that connects customers with trusted local service providers. Users can easily discover skilled professionals such as electricians, plumbers, carpenters, teachers, technicians, mechanics, and more in their area.

## 🚀 Features

* 🔍 Search and discover local service providers
* 👨‍🔧 Verified expert profiles
* 📍 Find services near your location
* ❤️ Save favorite providers
* 🔐 Secure authentication with Google OAuth
* 📱 Responsive and mobile-friendly design
* ⚡ Fast performance with Next.js
* 📊 SEO optimized pages

## 🛠️ Tech Stack

### Frontend

* Next.js
* React.js
* Tailwind CSS
* Zustand
* Axios

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication

### Deployment

* Vercel (Frontend)
* Cloudinary (Image Storage)
